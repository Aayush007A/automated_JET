### Data Overview 
 
				  
"This tab contains an overview for all the data input forms present in this file along with the descriptions of each individual field. 
Fields marked as required must be completed for every row.  Fields marked as optional do not need to be completed for every row, but the absence of data may impact your ability to produce certain analytics or affect your ability to link certain datasets, i.e. shipping to billing."				  
				  
				  
				  
In each data input form on the following tabs, the data types are color-coded as:				  
				  
Additionally, fields with a red border are for internal Deloitte use and will be completed by Deloitte professionals. These appear as: 				  
				  
IMPORTANT				  
Fields that are marked with Required* (suffixed with asterisk) are mandatory for 'Management Override - Journal Entry Testing' (MO-JE) in Omnia Data and must be populated with actual values or an alternative value if not available from the source system. Additional information is given in the Guidance column for each relevant field.				  
				  
Fields that are marked with Optional* have additional important information given in the Guidance column. Please refer to the provided guidance about conditions regarding these fields.
