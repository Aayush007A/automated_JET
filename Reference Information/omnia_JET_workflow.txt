Overview
Deloitte Omnia is a platform which aims to improve efficiency, the client and practitioner experience, and high-quality delivery.
1. Connect to VPN:
Start by connecting to the VPN for secure access.
2. Access Omnia Portal:
Once connected, go to the Omnia Portal.
3. Create/Select an Engagement:
In the portal, create a new engagement or select an existing one as needed.
4. Data Kitchen Access:
Navigate to Data Kitchen, where you can request data for your engagement.
5. Request Data:

•
Check CDR Form: Verify if a Client Data Request (CDR) form is available. If it is, proceed to the next step. If not, contact the engagement team.

•
Create Data Request: Use the CDR form to make a formal data request.
6. Upload Data:

•
Once the data is received, upload it to the "EFT_UP" folder within the data staging area.

•
If the data is not yet uploaded, click on "EFT_UP" to start the upload process.
7. Data Validation:
Data Integrity Check: Check the uploaded file for accuracy and completeness. If any discrepancies are found, re-upload corrected files.
8. Specialist Tool Access:

•
Use the advanced scripting tools if additional data processing or analysis is needed.

•
Access the workspace where you can find necessary resources and run notebooks for further data processing.
9. Run Notebooks:

•
Open and run the relevant Python notebooks to process data.

•
This step may include journal entry reconciliation and creation of final output files.
10. Upload Processed Files:

•
Upload the processed files one by one to the specific Data Kitchen folders.

•
Ensure the files follow the required naming format, such as "General_Ledger_Default.parquet."
11. End Process:
The workflow is complete once all required files are uploaded and available for review.
