# MAGIC   The schema refered to here are the column types. A column can be of type String, Double, Long, etc. Using inferSchema=false (default option) will give a dataframe where all columns are strings (StringType).

# MAGIC   By setting inferSchema=true, Spark will automatically go through the file and infer the schema of each column. This requires an extra pass over the file which will result in reading a file with inferSchema set to true being slower and is not recommended.

# MAGIC 3.**multiLine** 
# MAGIC    To parse records split across multiple lines due to carriage return into a single line. Set multiLine = True to correct for Split Line issues 
# MAGIC 
# MAGIC 4.**quote** 
# MAGIC    To quote fields/columns containing values where delimiter/separator can be part of the value. The default value is double quote.

# MAGIC 5.**escape** 
# MAGIC    To set a single character as escaping character to override default escape character(\) 
# MAGIC 
# MAGIC 6.**ignoreLeadingWhiteSpace** 
# MAGIC    To remove the leading spaces in all column names and column values

# The 'transform_journal_entry' function performs the below on the 'JE_Final_before_zero_exc' DataFrame: 
# 1. Excludes records where all the net amounts columns (net_amount_oc, net_amount_ec, net_amount_gc) are zero. 
# 2. Converts entity_id and account_number columns to upper case. 
# 3. Derives debit/credit amounts from net amount. 
# 4. Type casts fiscal_period field to Integer. 
# 5. Type casts numeric fields to Decimal. 
# 6. Removes Single and Double Quotes in string fields. 
# 7. Produces the 'Journal Entry Tie-Out' table - helpful for review/validation and tie-out purposes. 
#       '1. Mapped JE' relates to the 'JE_Final_before_zero_exc' DataFrame from section 3.3 
#       '2. Excluded JE' relates to the 'JE_ZeroLines' DataFrame which contains the records with zero net amounts 
#       '3. Final JE' relates to the 'JE_Final' DataFrame after excluding records with zero net amounts,  
#       and all the amount columns (net/debit/credit oc/ec/gc) are rounded to 6 decimal places 
#       '4. Truncated JE' relates to the 'JE_Final' DataFrame after excluding records with zero net amounts,  
#       and all the amount columns (net/debit/credit oc/ec/gc) are truncated to 2 decimal places to help tie-out with the Golden Checks output
